# 섯다 게임 (Korean Seotda Card Game)

온라인 멀티플레이어 섯다 게임입니다. 최대 8명까지 동시에 플레이할 수 있습니다.

## 🎮 게임 링크
**[섯다 게임 플레이하기](https://wonjoon0617.github.io/jeju-flight-tracker/seotda.html)**

## 🃏 게임 특징

### 기본 규칙
- **플레이어**: 최대 8명까지 참여 가능
- **카드**: 1월~10월 각 2장 (총 20장), 1월/3월/8월 중 한 장은 광 카드
- **베팅**: 1잔씩 올리기, 최대 4잔 (베팅 유지 시 추가 4잔)

### 특수 기능
- **참여형 게임**: 닉네임으로 입장, 실시간 멀티플레이어
- **카드 비공개**: 자신의 카드만 보이고, 다른 플레이어 카드는 뒷면
- **순차 공개**: 결과 발표 시 참여 순서대로 카드 공개
- **자동 진행**: 라운드 자동 진행, 패배자 우선 순서

### 족보 순위 (높은 순서)
1. **암행어사** (4,7) - 광땡만 이김, 없으면 1끗
2. **땡잡이** (3,7) - 땡만 이김, 없으면 0끗
3. **구사파토** (4,9) - 2명 이상 시 베팅 유지
4. **38광땡** (3광,8광)
5. **13광땡** (1광,3광), **18광땡** (1광,8광)
6. **땡** - 10땡 > 9땡 > ... > 1땡
7. **알리** (1,2)
8. **독사** (1,4)
9. **구삥** (1,9)
10. **장삥** (1,10)
11. **장사** (4,10)
12. **세륙** (4,6)
13. **끗** - 9끗 > 8끗 > ... > 0끗

### 특수 룰
- **구사파토 승리**: 베팅 유지하고 다음 판 진행
- **동점 족보**: 베팅 유지하고 다음 판 진행
- **꼴등 상쇄**: 같은 족보끼리 상쇄, 모두 상쇄 시 베팅 유지
- **자동 베팅 종료**: 마지막 베터 차례 복귀 시 자동 종료

## 🎯 플레이 방법

1. **게임 참여**: 링크 접속 후 닉네임 입력하여 참여
2. **게임 시작**: 최소 2명 참여 시 "게임 시작" 가능
3. **베팅**: 자신의 차례에 다이/콜/1잔 올리기 선택
4. **결과 확인**: 순차적 카드 공개 후 승패 결정
5. **자동 진행**: 패배자부터 다음 라운드 자동 시작
